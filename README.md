# Portafolio de JeampyON

Sitio personal estático para presentar proyectos, tecnologías y enlaces de contacto.

🌐 **Sitio publicado:** [jeampyon.github.io](https://jeampyon.github.io/)

## Contenido

- Presentación personal y navegación adaptable a móviles.
- Proyectos destacados con descripciones y acceso a sus repositorios.
- Búsqueda y filtros por tecnología.
- Tema claro/oscuro con preferencia guardada en el navegador.

## Ejecutar localmente

Abre `index.html` en un navegador o inicia un servidor estático desde esta carpeta, por ejemplo:

```powershell
python -m http.server 5500
```

Luego visita `http://localhost:5500`.

El sitio usa HTML, CSS y JavaScript sin proceso de compilación. Se publica desde la rama `main` de este repositorio mediante GitHub Pages.
